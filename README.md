# 🦊 Booster Admin Panel

Фронтенд административной панели для приложения Booster.

**Стек:** React 18 + Vite + Tailwind CSS + Recharts

## Быстрый старт

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`

Бэкенд по умолчанию — `https://booster-back-production.up.railway.app` (задан в `src/services/api.js`). Чтобы указать другой (например, локальный или staging), скопируй `.env.example` в `.env` и задай `VITE_API_URL`; локальный прокси не используется, фронт всегда ходит по абсолютному URL.

## Войти в систему

Сид-админ (после `npm run seed` на бэкенде):
- Логин: `77000000000`
- Пароль: `Admin2025!`

## Страницы

| Страница | Путь | Описание |
|----------|------|----------|
| Дашборд | `/` | Статистика, графики, быстрые действия |
| Заявки | `/registrations` | Одобрение/отклонение регистраций |
| Пользователи | `/users` | Управление студентами, FOX, EXP |
| Квиз | `/quiz` | Вопросы и расписание Daily Quiz |
| Мини-игры | `/games` | Обзор игр и системы лимитов |
| Магазин | `/shop` | Товары за Фоксы |
| Образы | `/skins` | Гардероб (цельные образы, без категорий) |
| Лидерборд | `/leaderboard` | Рейтинг студентов |

## Роли (на будущее)

| Роль | Доступ |
|------|--------|
| `admin` | Всё |
| `teacher` | Просмотр пользователей, квиз, лидерборд |
| `marketer` | Магазин, скины, просмотр пользователей |
| `moderator` | Заявки, блокировка пользователей |

Роли управляются в `src/context/AuthContext.jsx` — объект `PERMISSIONS`.

## Деплой

**Vercel** (рекомендуемый способ):
1. Запушить репозиторий на GitHub.
2. Импортировать проект на [vercel.com](https://vercel.com) → Framework Preset: Vite, Build Command: `npm run build`, Output Directory: `dist` (определяется автоматически).
3. При необходимости задать переменную окружения `VITE_API_URL` в настройках проекта Vercel (Settings → Environment Variables) — иначе используется прод-URL бэкенда по умолчанию, зашитый в `src/services/api.js`.
4. `vercel.json` в корне уже настраивает rewrite всех путей на `index.html` — без этого прямые переходы на `/users`, `/quiz` и т.п. будут отдавать 404 (SPA-роутинг через `react-router`).

**Важно:** после первого деплоя нужно добавить домен фронтенда (например, `https://<project>.vercel.app`) в `ALLOWED_ORIGINS` на бэкенде — иначе CORS заблокирует все запросы из админки. Это делается на стороне бэкенд-репозитория/окружения, не здесь.

Другие статические хостинги (Netlify, Cloudflare Pages, GitHub Pages и т.п.) работают аналогично: `npm run build` → раздать содержимое `dist/` → настроить SPA-fallback на `index.html` для всех путей.
